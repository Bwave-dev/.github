  # BWAVE Inc.

  **정신과 마음이 건강한 사회를 만드는 기업**

  [![Website](https://img.shields.io/badge/Website-000000?style=flat-square&logo=googlechrome&logoColor=white)](https://www.bwaveeeg.com/)
</div>

BWAVE는 뇌파(EEG)와 심박변이도(HRV) 생체신호를 AI로 분석하는 디지털 정신건강 케어 플랫폼 **마음결(Maumgyeol)**을 개발합니다. ISO 9001 인증(2025).

## 마음결 서비스 라인업

| 서비스 | 플랫폼 | 설명 | 대상 |
|---|---|---|---|
| **마음결 미니** | Android / iOS | 스마트폰 카메라 PPG 측정 기반 심박·HRV 셀프케어 | B2C |
| **마음결 베이직** | Android 태블릿 | 2채널 EEG 측정 기기 연동 정신건강 평가 | B2B (기관·전문가) |
| 마음결 기어 *(예정)* | - | 고급 평가 | - |
| 마음결 프로 *(예정)* | - | 우울증·조현병·PTSD 임상 진단 | - |
